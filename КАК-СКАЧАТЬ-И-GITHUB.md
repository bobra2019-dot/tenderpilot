# Как забрать код: скачивание и GitHub

## 1. Почему кнопка «Скачать» не сработала

Файловый просмотрщик Arena открывает файлы в песочнице-iframe с флагом
`sandbox="allow-scripts"`. В такой песочнице браузер **блокирует загрузку файлов** —
это ограничение платформы, а не проблема архива. Поэтому архив нужно забирать
через работающий сервер или через git.

---

## 2. Скачать через сервер (самый быстрый способ)

Сервер приложения отдаёт архив по прямой ссылке. Пока приложение запущено:

1. Откройте панель превью **TenderPilot CRM** и нажмите **↗** (открыть в новой вкладке).
2. В адресной строке допишите **`/download`**:

   ```
   https://<адрес-превью>/download
   ```

3. На странице — большая кнопка **«⬇ Скачать TenderPilot.zip»** (~103 КБ).

Там же есть список всех файлов проекта по отдельности: можно открыть любой файл
и скопировать содержимое, если архив качать не хочется.

Прямые ссылки:

| Что | Ссылка |
|---|---|
| Весь проект архивом | `<адрес-превью>/download/TenderPilot.zip` |
| Страница со списком файлов | `<адрес-превью>/download` |
| Один файл | `<адрес-превью>/download/raw/app/main.py` |

> `адрес-превью` — это тот адрес, по которому у вас открывается приложение
> (вида `https://8000-xxxx.e2b.app`). Ссылки работают только пока сервер запущен;
> если сессия перезапустилась — напишите мне «перезапусти».

## 3. Залить в свой GitHub

У меня нет доступа к вашему GitHub: коннектор в этой среде недоступен (проверил —
ответ «unsupported»), поэтому запушить напрямую я не могу. Но в архиве лежит
готовый скрипт **`push-to-github.sh`** — он делает всё за вас.

### Порядок действий

1. Скачайте и распакуйте архив (способ из п. 2) либо склонируйте папку иначе.
2. На github.com создайте **пустой** репозиторий, например `tenderpilot`
   (без README и без .gitignore — иначе будет конфликт первого коммита).
3. В терминале, из папки проекта:

   ```bash
   chmod +x push-to-github.sh
   ./push-to-github.sh https://github.com/ВАШ_ЛОГИН/tenderpilot.git
   ```

   Или по SSH-ключу:

   ```bash
   ./push-to-github.sh git@github.com:ВАШ_ЛОГИН/tenderpilot.git
   ```

Скрипт сам: сделает `git init` (ветка `main`), создаст `.gitignore`,
закоммитит все 17 файлов, добавит `origin` и выполнит `git push -u origin main`.
Повторный запуск безопасен — обновит remote и запушит новые изменения.

### Те же шаги вручную

```bash
git init -b main
git add -A
git commit -m "TenderPilot: CRM автопастера тендеров с ИИ-анализом ТЗ и расчётом маржи"
git remote add origin https://github.com/ВАШ_ЛОГИН/tenderpilot.git
git push -u origin main
```

### Если GitHub просит пароль
С 2021 года обычный пароль не принимается — нужен **personal access token**:
GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
→ Generate new token, права `repo`. В качестве пароля вставляйте токен.
Либо настройте SSH-ключ и используйте адрес `git@github.com:...`.

### Что попадёт в репозиторий

```
app/       бэкенд: FastAPI, скоринг, ИИ-слой, парсер, демо-данные
web/       фронтенд: SPA без зависимостей и CDN
data/      SQLite с демо-профилем завода и 23 закупками
README.md  описание, архитектура, план вывода в прод
bootstrap.sh / run.sh   установка зависимостей и запуск одной командой
КАК-ОТКРЫТЬ.md          эта инструкция
```

Кэш, `__pycache__`, `*.pyc` и WAL-файлы базы исключены через `.gitignore`.
Если базу с демо-данными в репозиторий не нужно — удалите строку `data/tenderpilot.db`
из индекса: `git rm --cached data/tenderpilot.db`.

## 4. Запуск после скачивания

```bash
cd TenderPilot
./bootstrap.sh          # поставит зависимости и запустит сервер
```

Откройте http://localhost:8000, вход: `owner@zavod.ru` / `demo1234`.

Windows без bash:

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
