# Как открыть и скачать TenderPilot

## 1. Открыть прямо сейчас (без установки)

Сервер уже запущен в этой сессии. В интерфейсе Arena есть панель предпросмотра —
она подписана **«TenderPilot CRM»** и показывает порт **8000**.

- Нажмите на неё, чтобы развернуть.
- Кнопка «открыть в новой вкладке» (значок ↗) откроет сайт на весь экран.

**Логин:** `owner@zavod.ru`
**Пароль:** `demo1234`

Что посмотреть в первую очередь:
1. **Дашборд** — топ рекомендаций ИИ и ближайшие дедлайны.
2. **Лента тендеров** — фильтры по вердикту/площадке, сортировка по марже.
3. Клик по закупке → вкладки **ИИ-заключение**, **ТЗ и требования**, **Экономика**
   (там живой калькулятор маржи).
4. **Настройки ИИ** → провайдер + API-ключ → «Проверить подключение».

> Важно: если сессия среды перезапустилась, предпросмотр покажет ошибку — при перезапуске
> сбрасываются установленные Python-библиотеки (файлы и база сохраняются).
> Напишите «перезапусти» — я подниму за 10 секунд. У себя локально просто выполните
> `./bootstrap.sh` — он сам поставит зависимости и запустит сервер.

## 2. Скачать архив
> **Не срабатывает кнопка «Скачать»?** Просмотрщик Arena открывает файлы в песочнице-iframe,
> где браузер блокирует загрузку. Используйте страницу `<адрес-превью>/download`
> или git — пошагово в файле **КАК-СКАЧАТЬ-И-GITHUB.md**.


Файл: **`dist/TenderPilot.zip`** (~99 КБ) — откройте его в панели файлов
справа и нажмите «Скачать».

Внутри: весь код, база с демо-данными и уже посчитанными ИИ-заключениями,
`README.md` и скрипт запуска.

## 3. Запустить у себя на компьютере

Нужен Python 3.10+ ([python.org/downloads](https://www.python.org/downloads/),
при установке на Windows отметьте «Add Python to PATH»).

```bash
# 1. распакуйте архив, зайдите в папку
cd TenderPilot

# 2. одна команда — поставит зависимости и запустит сервер
./bootstrap.sh
```

Если скрипт не запускается (например, на Windows без bash) — те же шаги вручную:

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**Windows:** то же самое в PowerShell или cmd.
**Mac/Linux:** можно короче — `./run.sh`

Откройте в браузере **http://localhost:8000** и войдите тем же логином.

### Если `pip` не найден
- Windows: `py -m pip install -r requirements.txt`, затем `py -m uvicorn app.main:app --port 8000`
- Mac/Linux: `python3 -m pip install -r requirements.txt`, затем `python3 -m uvicorn app.main:app --port 8000`

### Как подключить настоящий ИИ
1. Получите ключ: OpenAI (`platform.openai.com`), DeepSeek (`platform.deepseek.com`,
   дешевле всего), либо OpenRouter — один ключ на Claude/GPT/Gemini.
2. В приложении: **Настройки ИИ** → выберите провайдера, вставьте ключ → **Проверить подключение** → **Сохранить**.
3. Откройте любую закупку и нажмите **«Обновить заключение ИИ»** — теперь анализ делает модель,
   в бейдже будет название модели вместо «встроенный расчёт».

### Сбросить демо-данные
Удалите файл `data/tenderpilot.db` и перезапустите — база создастся заново
с демо-профилем завода «ПромАрматура» и 23 закупками.

### Частые проблемы
| Симптом | Решение |
|---|---|
| `No module named uvicorn` / `fastapi` | сбросились зависимости — выполните `pip install -r requirements.txt` или `./bootstrap.sh` |
| `Address already in use` | порт занят: добавьте `--port 8001` и откройте `localhost:8001` |
| Страница пустая, в консоли 401 | истёк вход — обновите страницу и войдите заново |
| «Ошибка LLM: 401» | неверный API-ключ или выбран не тот провайдер |
