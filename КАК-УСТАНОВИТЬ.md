# Как скачать и установить TenderPilot на Windows

Ничего печатать в командной строке не нужно. Три шага: **скачать → распаковать → двойной клик**.

---

## Шаг 1. Скачать

Откройте в браузере ссылку (она сразу скачивает архив, копировать не нужно — просто нажмите):

**https://github.com/bobra2019-dot/tenderpilot/archive/refs/heads/main.zip**

Появится файл `tenderpilot-main.zip` в папке «Загрузки».

---

## Шаг 2. Распаковать

1. Найдите файл `tenderpilot-main.zip` в «Загрузках».
2. **Правая кнопка → «Извлечь всё…» → «Извлечь».** (Не открывайте архив двойным кликом — нужно именно извлечь.)
3. Получится папка `tenderpilot-main`. Перенесите её куда удобно — например, `C:\TenderPilot`
   (путь без русских букв надёжнее).

Внутри должны лежать: `start.bat`, `requirements.txt`, папки `app`, `web`, `data`.

> Если Windows показывает «Не удаётся безопасно извлечь» — нажмите «Дополнительные сведения» → «Всё равно извлечь».

---

## Шаг 3. Один раз поставить Python

Нужен только при первой установке.

1. Откройте **https://www.python.org/downloads/release/python-3129/**
2. Прокрутите вниз до таблицы **Files** и нажмите **«Windows installer (64-bit)»**.
3. Запустите скачанный файл. На **первом** экране поставьте галочку внизу
   **«Add python.exe to PATH»** — это важно — и нажмите **Install Now**.
4. Дождитесь «Setup was successful» → Close.

Если Python уже стоит — этот шаг пропустите, `start.bat` сам его найдёт.

---

## Шаг 4. Запустить

1. Откройте папку `tenderpilot-main` (или `C:\TenderPilot`).
2. **Двойной клик по `start.bat`.**
3. Откроется чёрное окно, оно само поставит библиотеки — **1–3 минуты**, идёт установка.
   В это время ничего не закрывайте.
4. Затем автоматически откроется браузер с адресом **http://localhost:8000**.

### Вход

- Логин: **owner@zavod.ru**
- Пароль: **Tender2026**

Это администратор системы. **Сразу смените пароль**: кнопка «ключ» в левом нижнем
углу → введите текущий и новый.

> Чёрное окно — это и есть сервер. Пока оно открыто, приложение работает.
> Чтобы выключить — закройте окно (или Ctrl+C в нём).

## Что настроить в первые 10 минут

| Что | Где | Зачем |
|---|---|---|
| Ключ ИИ | «Настройки ИИ» → вставить ключ → «Проверить ключ» | без ключа вердикты ИИ не формируются |
| Профиль завода | «Профиль завода» | номенклатура, ОКПД2, регионы, экономика — от них зависят оценки и маржа |
| Источники | «Источники данных» → включить «ЕИС • 44-ФЗ», ключевые слова → «Собрать сейчас» | живой поиск закупок работает с российского IP (то есть с вашего компьютера) |
| Выгрузки площадок | «Источники данных» → «Выгрузить и разобрать» или папка `inbox` | Excel/CSV с Росэлторга, B2B-Center, ЭТП ГПБ |
| Telegram | там же, токен бота из @BotFather и ваш chat_id из @userinfobot | уведомления по закупкам с вердиктом «идём» |
| Пользователи | «Администрирование» | подтверждать заявки, создавать учётки, роли |

## Как обновить до новой версии

1. Скачайте тот же ZIP заново и распакуйте.
2. Скопируйте из **новой** папки файлы `app`, `web`, `requirements.txt`, `start.bat` в свою папку
   (`C:\TenderPilot`), заменяя старые.
3. **Папку `data` не трогайте** — там ваша база с пользователями и закупками.

Или проще: пусть кто-то один раз настроит синхронизацию — но и способ выше работает без программ.

## Где лежат данные и как сделать резервную копию

- `data\tenderpilot.db` — вся база: пользователи, закупки, профили, настройки.
- `inbox\` — сюда можно класть XML/CSV-выгрузки, они разбираются автоматически.

Резервная копия = скопировать папку `data` в другое место (флешка, облако). Раз в неделю достаточно.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Окно мигнуло и закрылось | Правый клик по `start.bat` → «Запустить от имени администратора»; или проверьте, что Python стоит (Шаг 3) |
| «Python not found» | Python не установлен или галочка «Add python.exe to PATH» не стояла. Переустановите Python по Шагу 3 |
| «ERROR: libraries could not be installed» | Слишком новый Python (3.14). Поставьте 3.12 по Шагу 3 — `start.bat` выберет его сам |
| Windows пишет «Защита Windows предотвратила…» | «Подробнее» → «Выполнить всё равно». Файл `.bat` — это ваш же скрипт запуска |
| Браузер не открылся сам | Откройте вручную http://localhost:8000 |
| «Порт 8000 уже занят» | Закройте другое окно с сервером (возможно, предыдущий запуск) |
| Долго ставится и пишет красное про сеть | Нет доступа в интернет или блокирует антивирус. Проверьте сеть, повторите запуск |
| В «Источниках данных» ЕИС «недоступен» | Проверьте, что интернет не через зарубежный VPN; ЕИС открывается только с российских адресов |

## Второй вариант: постоянный адрес в интернете

`start.bat` — это доступ только с вашего компьютера. Чтобы приложение было доступно по
постоянной ссылке (в том числе с телефона и для сотрудников), его ставят на VPS —
подробная инструкция в файле **`УСТАНОВКА-НА-СЕРВЕР.md`** в той же папке.
Для сервера за границей там же описано, как настроить российский прокси для ЕИС.
