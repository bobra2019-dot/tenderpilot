# TenderPilot — закрытая CRM для тендеров завода

Система для владельца завода: профиль производства настраивается один раз, дальше она сама
мониторит закупки на площадках, ИИ читает ТЗ, сверяет требования с вашими возможностями,
считает маржу и выдаёт вердикт **«идём / спорно / не идём»**.

**Стартовый доступ:** `owner@zavod.ru` / `Tender2026` — администратор. Смените пароль при первом входе.

---

## Что входит

| Блок | Что делает |
|---|---|
| **Профиль завода** (5 шагов) | Название, ИНН, регион, направления производства (7 отраслевых каталогов с ОКПД2), продукция, коды ОКПД2, сертификаты и декларации, лицензии и СРО, регионы поставки, опыт, производственный цикл, мин./макс. сумма заказа, экономика (материалы, труд, накладные, логистика, БГ, резерв на риски, минимальная и целевая маржа), веса скоринга |
| **Сбор закупок** | Живой поиск ЕИС (44/223-ФЗ), разбор официального XML ЕИС, папка `inbox` с выгрузками ЭТП (CSV/Excel), API площадки по договору. Дедупликация по паре «площадка + номер», журнал сбора, расписание по интервалу |
| **Лента тендеров** | Фильтры по вердикту, площадке, категории, закону, этапу; сортировка по соответствию / дедлайну / сумме / марже; поиск по названию, заказчику, номеру и **тексту ТЗ** |
| **Ручное добавление** | Ссылка, текст извещения или файл ТЗ (**docx / pdf / txt**): парсер вытаскивает сумму, ОКПД2, закон, площадку, регион, срок поставки, дедлайн и требования — создаёт карточку и сразу отправляет в ИИ |
| **ИИ-заключение** | Что подходит и почему, проверка каждого требования ТЗ (выполнено / частично / нет), риски по уровням, признаки ограничения конкуренции, вероятность победы, рекомендуемая цена и запас на торг, что готовить в заявку, следующие шаги, вопросы заказчику |
| **Экономика** | Себестоимость + коэффициент логистики по региону + банковская гарантия + резерв на риски + НДС/УСН: маржа в рублях и %, безубыточная цена, потребность в оборотном капитале. Живой калькулятор «а если» |
| **Воронка и аналитика** | Этапы (новый → на проверке → готовим заявку → подана → выигран/проигран/отклонён), дашборд с топом рекомендаций и дедлайнами, аналитика по площадкам, распределение вердиктов, win rate |
| **Пользователи и доступ** | Регистрация с подтверждением администратора, роли (администратор / менеджер / наблюдатель), у каждого своя лента и профиль завода, блокировка, сброс паролей |
| **Уведомления** | Telegram-бот и e-mail по закупкам с вердиктом «идём» |
| **Печать заключения** | Печатная версия карточки для внутреннего согласования |

### Как считается оценка

Скоринг — взвешенная сумма: ОКПД2 (30%), совпадение по ТЗ (25%), объём к мощности (15%),
география (10%), сроки (10%), сертификаты (10%). Веса настраиваются в профиле.

- **Не идём** — нет обязательного сертификата/допуска/опыта, маржа ≤ 0 или профиль не совпадает.
- **Спорно** — профильное и маржинальное, но есть незакрытые требования, либо соответствие ниже 72.
- **Идём** — соответствие ≥ 72, маржа выше вашего минимума, все требования закрыты.

## Публичный сайт и заявки

Корень сайта (`/`) — страница продаж для гостя; авторизованный пользователь сразу попадает в кабинет.
Отдельные адреса: `/pricing`, `/legal` (оферта, политика данных, правила), `/robots.txt`, `/sitemap.xml`.

- Кнопка «Получить разбор» и «запросить счёт» открывают форму заявки. Заявка попадает в админку →
  блок **«Заявки с сайта»**, там же смена статуса (новая → в работе → клиент → отказ) и выгрузка CSV.
- Контакты для шапки, подвала и кнопки «Связаться» задаются в админке → **«Контакты на сайте»**.
  Пока пусто — в шапке контактов нет.
- Реквизиты организации для счетов заполняются в админке → **«Реквизиты для счетов»** (ИНН, КПП, адрес,
  расчётный счёт, банк, БИК, корр. счёт). Пока пусто — в счёте стоит пометка «не заполнено».
- Есть защита от спама: ограничение 5 заявок в час с одного адреса и отсев контактов со ссылками.

## Установка

### На сервер (VPS) — одна команда

```bash
curl -fsSL https://raw.githubusercontent.com/bobra2019-dot/tenderpilot/main/install-vps.sh | bash
```

Скрипт поставит Docker, развернёт приложение в `/opt/tenderpilot`, запустит его и напечатает адрес.
Подробно, с доменом, HTTPS и российским прокси для ЕИС — в **[УСТАНОВКА-НА-СЕРВЕР.md](УСТАНОВКА-НА-СЕРВЕР.md)**.

Вручную:

```bash
git clone https://github.com/bobra2019-dot/tenderpilot.git
cd tenderpilot
cp .env.example .env          # PUBLIC_URL=https://ваш-домен
docker compose up -d --build
```

### На Windows

1. Скачать: https://github.com/bobra2019-dot/tenderpilot/archive/refs/heads/main.zip
2. Распаковать архив («Извлечь всё»).
3. Один раз поставить Python 3.12: https://www.python.org/downloads/ (галочка **Add python.exe to PATH**).
4. Двойной клик по `start.bat` — окно само поставит зависимости и откроет браузер на `http://localhost:8000`.

Подробно — в **[КАК-УСТАНОВИТЬ.md](КАК-УСТАНОВИТЬ.md)**.

### На Linux без Docker

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Один воркер обязателен: планировщик сбора и SQLite живут в процессе.

## Подключение ИИ

«Настройки ИИ» → ключ провайдера → «Проверить ключ». Поддерживаются OpenAI, Anthropic,
DeepSeek, OpenRouter и любой OpenAI-совместимый endpoint.

Без ключа работают скоринг, экономика и встроенная эвристика разбора — вердикты формируются,
но без чтения ТЗ моделью. Ключ хранится в вашей базе, наружу не отдаётся.

## Источники закупок

| Источник | Как работает |
|---|---|
| **ЕИС 44-ФЗ / 223-ФЗ** | живой поиск по zakupki.gov.ru: номер, НМЦК, ОКПД2, регион, заказчик, дедлайн. Требует российский IP — площадка не отвечает зарубежным адресам; для сервера за границей есть поле «Прокси для ЕИС» и переменная `EIS_PROXY` |
| **Папка `inbox`** | XML ЕИС и CSV/Excel-выгрузки Росэлторга, B2B-Center, ЭТП ГПБ, ТЭК-Торга разбираются автоматически, колонки распознаются |
| **API площадки** | адрес и Bearer-токен по договору с ЭТП |

Дедупликация — по паре «площадка + номер закупки». Расписание и уведомления настраиваются
в «Источниках данных».

## Данные и резервная копия

- `data/tenderpilot.db` — вся база: пользователи, закупки, профили, настройки.
- `inbox/` — сюда можно класть выгрузки, они разбираются автоматически.

Копия = сохранить папку `data`. Восстановление = вернуть её на место и перезапустить.

## Структура проекта

```
tenderpilot/
├── app/
│   ├── main.py       API: авторизация, пользователи, тендеры, анализ, парсер, статистика
```

## Что учесть при работе с реальными данными

- Смените стартовый пароль администратора и включите подтверждение регистрации.
- Поставьте домен и HTTPS: без них пароль и данные идут по сети открыто.
- Для нескольких сотрудников используйте отдельные учётные записи с ролями, а не общий пароль.
- Резервная копия базы — раз в неделю, в отдельное место.
- SQLite рассчитан на один сервер. При росте нагрузки и числа пользователей базу переносят на PostgreSQL.
