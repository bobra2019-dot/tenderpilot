# Установка TenderPilot на ваш VPS (Нидерланды)

Сервер в Нидерландах для сайта подходит полностью. Проблема одна: ЕИС (zakupki.gov.ru)
не отвечает на иностранные адреса. Решение — российский прокси только для запросов к ЕИС.
Весь остальной трафик идёт напрямую, сайт работает быстро.

```
Браузер  →  https://ваш-домен  →  VPS в Нидерландах (Docker, TenderPilot)
                                        │
                                        └─ только запросы к zakupki.gov.ru → российский прокси
```

---

## Шаг 1. Подключиться к серверу

Из Windows: Win + R → `cmd` → Enter, затем:

```
ssh root@IP-ВАШЕГО-СЕРВЕРА
```

Пароль — из письма хостера (или ключ, если настраивали).

## Шаг 2. Поставить Docker (5 минут, одна команда)

Ubuntu/Debian:

```
curl -fsSL https://get.docker.com | sh
```

Проверка: `docker --version` должен показать версию.

## Шаг 3. Скачать приложение и запустить

```
cd /opt
git clone https://github.com/bobra2019-dot/tenderpilot.git
cd tenderpilot
cp .env.example .env
docker compose up -d --build
```

Через 2–3 минуты сайт открывается по адресу `http://IP-ВАШЕГО-СЕРВЕРА:8000`.

Папки `data/` (база) и `inbox/` (выгрузки площадок) лежат рядом с приложением —
при обновлении не теряются. Автоперезапуск при сбое и после перезагрузки сервера включён.

Обновление до новой версии:

```
cd /opt/tenderpilot && git pull && docker compose up -d --build
```

## Шаг 4. Российский прокси для ЕИС

Два варианта, оба бесплатны в настройке:

**А. Второй маленький VPS в России** (Timeweb, Selectel, Reg.ru — от 200 ₽/мес, самый дешёвый тариф):

```
# на российском сервере
apt update && apt install -y squid
# затем в /etc/squid/squid.conf добавить свою строку и перезапустить:
#   acl home src IP-АДРЕС-ВАШЕГО-НИДЕРЛАНДСКОГО-СЕРВЕРА
#   http_access allow home
#   http_access deny all
systemctl restart squid
```

**Б. Готовый российский прокси** — покупается у любого провайдера прокси в РФ (200–500 ₽/мес),
выдаётся строка вида `http://логин:пароль@185.10.10.10:8888`.

Дальше в приложении: **Источники данных → ЕИС • 44-ФЗ → поле «Прокси для ЕИС»** —
вставить строку, включить источник, «Сохранить настройки», «Собрать сейчас».

Проверить, что прокси живой, можно кнопкой **«Проверить доступность площадок»**:
когда прокси прописан, ЕИС должен стать «доступен».

## Шаг 5. Домен и HTTPS

Если домен уже указывает на сервер (A-запись → IP), поставьте Caddy — он сам получит
сертификат и будет проксировать на приложение:

```
apt install -y caddy
nano /etc/caddy/Caddyfile
```

Содержимое (подставьте свой домен):

```
tenders.ваш-домен.ru {
    reverse_proxy 127.0.0.1:8000
}
```

```
systemctl restart caddy
```

Сайт будет по адресу `https://tenders.ваш-домен.ru`. Не забудьте поправить `PUBLIC_URL`
в `.env` на этот адрес и выполнить `docker compose up -d`.

## Шаг 6. Что включить внутри приложения

1. **Настройки ИИ** → вставить ключ (OpenAI / Anthropic / DeepSeek / OpenRouter) → «Проверить ключ».
   Без ключа работает только арифметика скоринга и маржи, вердикты не формируются.
2. **Профиль завода** → номенклатура, ОКПД2, регионы, экономика. От этого зависят вердикты.
3. **Источники данных** → включить ЕИС 44/223-ФЗ, задать ключевые слова и прокси.
4. Там же — **Telegram**: токен бота из @BotFather, ваш chat_id из @userinfobot,
   «Проверить уведомление».
5. **Расписание**: включить автоматический сбор, интервал 60 минут.
6. Пароль владельца смените сразу: логин `owner@zavod.ru`, текущий пароль `demo1234`.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `docker compose up` ругается на порт | занят 8000 — поменяйте в `docker-compose.yml`: `"8080:8000"` |
| ЕИС в журнале: «не отвечает зарубежным адресам» | не указан/не работает прокси (шаг 4) |
| Уведомления не приходят | неверный chat_id: напишите боту в Telegram и проверьте `/getUpdates` |
| Сайт открылся, но пустая лента | сбор ещё не запускался: «Источники данных» → «Собрать сейчас» |
| Нужны логи | `docker compose logs -f --tail 100` |
