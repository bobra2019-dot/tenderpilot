# Забрать код TenderPilot: три способа

## Что произошло у вас

Вы попали на страницу с текстом `run.sh` — это не ошибка и не «сайт вместо файла».
Так выглядят ссылки на отдельные файлы проекта: браузер открывает их как обычный текст
(в коде это `text/plain`). Скачивание архива при этом не запускалось по другой причине:

> Предпросмотр Arena открывает приложение в песочнице-iframe (`sandbox="allow-scripts"`).
> В такой песочнице браузер **запрещает любую загрузку файлов** — кнопка «Скачать»
> внутри превью не сработает никогда. Это ограничение платформы, а не архива.

Ниже три способа. **Способ 1 — самый надёжный, он работает даже внутри превью.**

---

## Способ 1 (надёжный): один файл копированием — без скачивания

1. Откройте страницу **`/single`** на работающем сайте.
   В превью: панель **TenderPilot CRM** → значок **↗** → в адресе допишите `/single`.
   Либо на странице `/download` нажмите «Способ без скачивания».
2. Нажмите кнопку **«Выделить весь код»**, затем **Ctrl+C**
   (на Mac — **Cmd+C**). Кнопка сама копирует текст в буфер.
3. Откройте **Блокнот** (Windows) или TextEdit / gedit (Mac/Linux), вставьте **Ctrl+V**.
4. Сохраните файл под именем **`tenderpilot.py`**
   - Windows: «Тип файла» → **Все файлы**, имя строго `tenderpilot.py`,
     кодировка — **UTF-8**. Иначе получится `tenderpilot.py.txt`.
5. В терминале в папке с файлом:

   ```bash
   python tenderpilot.py
   ```

   Файл сам распакует проект в папку `TenderPilot`, поставит зависимости и запустит сервер.
6. Откройте **http://localhost:8000**, вход `owner@zavod.ru` / `demo1234`.

Проверено: этот файл (104 КБ) разворачивает проект и поднимает рабочий сервер
с нуля, на чистой папке.

## Способ 2: архив в новой вкладке

1. В панели предпросмотра нажмите **↗** — сайт откроется в отдельной вкладке браузера.
2. Допишите в конец адреса **`/download`** и нажмите Enter.
3. Кнопка **«⬇ Скачать архив TenderPilot.zip»** (110 КБ) сработает —
   в обычной вкладке загрузки не блокируются (сервер отдаёт файл
   с заголовком `Content-Disposition: attachment`).

> В самом превью эта кнопка не работает by design — предупреждение об этом
> выводится прямо на странице `/download`.

## Способ 3: скопировать нужные файлы по отдельности

На странице `/download` ниже — список всех файлов проекта. Любой открывается
как текст: **Ctrl+A → Ctrl+C** и сохранить под тем же именем в нужную папку.
Пригодится, если нужно поправить один файл, не забирая весь проект.

Структура для ручного воссоздания:

```
TenderPilot/
├── app/      __init__.py, main.py, ai.py, scoring.py, catalog.py, db.py, seed.py
├── web/      index.html, app.js, styles.css
├── requirements.txt
└── run.sh
```

## Залить в GitHub

Коннектор GitHub в этой среде **недоступен** (проверял — ответ `unsupported`),
поэтому запушить за вас я не могу. Но когда код окажется у вас на компьютере —
это одна команда. В проекте лежит скрипт **`push-to-github.sh`**:

1. На github.com создайте **пустой** репозиторий, например `tenderpilot`
   (без README и .gitignore — иначе будет конфликт первого коммита).
2. В терминале из папки проекта:

   ```bash
   chmod +x push-to-github.sh
   ./push-to-github.sh https://github.com/ВАШ_ЛОГИН/tenderpilot.git
   ```

Скрипт сделает `git init` (ветка `main`), закоммитит все файлы, добавит `origin`
и выполнит `git push -u origin main`. Повторный запуск безопасен.

Вручную то же самое:

```bash
git init -b main
git add -A
git commit -m "TenderPilot: CRM автопастера тендеров с ИИ-анализом ТЗ и расчётом маржи"
git remote add origin https://github.com/ВАШ_ЛОГИН/tenderpilot.git
git push -u origin main
```

**Если GitHub просит пароль** — обычный пароль не подойдёт с 2021 года. Нужен
personal access token: GitHub → Settings → Developer settings → Personal access
tokens → Tokens (classic) → Generate new token, галочка `repo`. Вставляйте токен
вместо пароля. Либо настройте SSH-ключ и используйте адрес `git@github.com:...`.

### Уже через GitHub — на любой компьютер

После пуша скачивание больше не нужно: на другом компьютере достаточно `git clone`.

```bash
git clone https://github.com/ВАШ_ЛОГИН/tenderpilot.git
cd tenderpilot
./bootstrap.sh
```

## Запуск после того, как код оказался локально

```bash
cd TenderPilot
./bootstrap.sh
```

Скрипт ставит зависимости (если их нет) и поднимает сервер на
**http://localhost:8000**, вход `owner@zavod.ru` / `demo1234`.

Windows без bash:

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```
